# IPL-Data-Analysis
This project presents a detailed analysis of cricket match data using Python, Pandas, and Matplotlib. By processing ball-by-ball data, it answers 28 insightful queries related to team performance, player statistics, and match dynamics.
📊 Key Objectives & Insights
The analysis addresses 28 insightful questions about cricket match performance, team dynamics, player stats, and match trends. Below are the areas covered:

🧮 Team and Player Statistics
Total runs scored by each batting team and each batsman

Average runs per inning by team and comparison across bowling teams

Matches played by each batting team

Highest average runs per match among batting teams

Runs scored in super overs and their distribution by team

🎯 Bowling & Fielding Insights
Number of wides, no balls, and other extras conceded by bowling teams

Most economical bowler

Most wickets taken and by which bowler

Dismissals by type, and fielder involvement

Most common dismissal type

📈 Over-by-Over Analysis
Total runs and extras scored per over

Run variations with over number

Wide and extra ball trends by over

🔁 Super Over Analysis
Total super overs played

Average runs in super over innings

Run distribution in super overs

⚔️ Player Matchups
Runs scored by each batsman-bowler pair

Batsmen with centuries

🔬 Exploratory Relationships
Correlation between:

Runs and extras

Wides and no-balls

Dismissal kinds and frequency

Over number and extras

📂 Tools & Libraries Used
Python 3.x

Pandas: Data manipulation and aggregation

Matplotlib / Seaborn: Data visualization

Jupyter Notebook: Exploratory data analysis

📌 Conclusion
This project provides a data-driven look into cricket analytics, revealing patterns in performance and decision-making in matches. It can be used by analysts, cricket enthusiasts, or anyone exploring sports data science.
